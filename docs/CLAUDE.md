# docs/

English files are canonical. Files ending in `.es.md` are Spanish translations of the same-named English file and carry no additional information.

- Read only the English versions (`integration-architecture.md`, `integration-security.md`). Do not open `*.es.md` unless the task is explicitly about translations.
- When you change an English doc, its Spanish counterpart goes stale. Update it in the same change if the task allows; otherwise tell the user it needs re-syncing.
- Keep the language bar (`[English](x.md) | [Español](x.es.md)`) as the first line of both files, and the "canonical version" note as the first blockquote of the Spanish one.
